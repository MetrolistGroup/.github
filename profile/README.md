## About

This organization hosts **Metrolist** and every service, tool, and fork that supports it — from the Android app itself to its real-time listen-together backend, moderation bot, website, and supporting libraries.

> ⚠️ **Metrolist (the app) is currently in maintenance mode** — bug fixes and small improvements only. It's not dead; follow along on [Discord](https://dsc.gg/metrolist) for updates.

## Projects

| Repository | Description | Stack |
|---|---|---|
| [**Metrolist**](https://github.com/MetrolistGroup/Metrolist) | The flagship Android app — stream, download, and manage YouTube Music with a Material 3 interface | Kotlin |
| [**metroserver**](https://github.com/MetrolistGroup/metroserver) | High-performance backend powering the app's "Listen Together" real-time feature | Go |
| [**metrobot**](https://github.com/MetrolistGroup/metrobot) | Discord/Telegram bot for the Metrolist community | Go |
| [**metrosite**](https://github.com/MetrolistGroup/metrosite) | The official Metrolist website ([metrolist.cc](https://metrolist.cc)) | Vue |
| [**faraday**](https://github.com/MetrolistGroup/faraday) | Remote configuration registry for YouTube player settings | TypeScript |
| [**innertubex**](https://github.com/MetrolistGroup/innertubex) | Extended InnerTube API client library for Kotlin | Kotlin |
| [**metroproto**](https://github.com/MetrolistGroup/metroproto) | Shared protocol definitions for the listen-together feature | Protobuf |
| [**MetrolistManager**](https://github.com/MetrolistGroup/MetrolistManager) | Build manager for Metrolist-KMP Windows builds | Go |
| [**MetrolistExtractor**](https://github.com/MetrolistGroup/MetrolistExtractor) | Extractor service (fork of PipePipeExtractor) | Java |
| [**metrolist-coverart-lib**](https://github.com/MetrolistGroup/metrolist-coverart-lib) | Native library for embedding M4A cover art metadata via Bento4 | C++ |
